# Android

Android 版のアプリは、デスクトップ版と同じ移植版に画面上のタッチパッドを加えたものです。デスクトップ版と同じくゲームのデータは含まれていません。起動するたびに、お手持ちのディスクイメージからゲームを読み込みます。

## 必要なもの

- Android 13 以降と、Vulkan 1.3 に対応した GPU ドライバー。
- Redump 形式の `.cue`/`.bin` イメージにしたお手持ちのディスク: 北米版（SLUS-00664）または日本版（SLPS-01160）。それぞれの `.cue` は対応する `.bin` の隣に置きます。

各リリースには APK が 2 つあります。スマートフォンとタブレットでは、名前に `arm64-v8a` が入っているほうを使います。`x86_64` のほうはエミュレーターと x86 の Chromebook 用です。

## インストール

1. APK とその `.sha256` ファイルを、同じ[リリース](https://github.com/EtherAura/xenogears-pc/releases)からダウンロードします。
2. ダウンロードしたファイルを確認します。SHA-256 が `.sha256` ファイルの値と一致している必要があります。Android SDK のビルドツールがあれば、署名した人も確認できます。`apksigner verify --print-certs <file>.apk` が報告する証明書の SHA-256 ダイジェストが `5dd2ee3620a373151c959f76a9bda01c0dd7c8066084e75f5ecdf73952912ffb` であることを確かめてください。すべてのリリースはこの証明書で署名されています。
3. 端末で APK を開き、インストーラーの指示に従います。Android に求められたら、APK を開いたアプリにアプリのインストールを許可します。この許可はインストール後にまたオフにできます。Android がインストールをブロックする場合は、下の説明を参照してください。
4. アプリを起動します。初回は、システムのフォルダー選択画面がディスクイメージの入ったフォルダーを尋ねます。イメージはその場所のまま読み込まれ（1 つ下のフォルダー、つまりディスクごとのフォルダーからも読み込みます）、何もコピーされません。アプリはそのフォルダーへのアクセスを保ちます。同じフォルダーに PlayStation の BIOS イメージがあれば、それも使われます。

更新するときは、新しい APK を古い APK の上からインストールします。同じ証明書で署名された APK なら、セーブデータ、設定、ステートセーブはそのまま残ります。アンインストールすると、これらは削除されます。メニューの セーブ（Saves） > バックアップ（Backup） では、セーブフォルダーを選んだ 1 つの `.zip` ファイルに書き出し、そこから復元できます。

## Android が開発者の確認を求める場合

Google は、認定済みの Android スマートフォンとタブレットで、アプリの開発者確認を導入しています。いくつかの国から始まり、その後は全世界に広がります。このアプリの開発者は確認を受けていません。この決まりが適用される端末では、Android はインストールがブロックされたと表示します。それでも、次のどちらかの方法でインストールできます。

**高度なフロー（advanced flow）。** 端末で一度だけ行う設定です。システム設定で開発者向けオプションをオンにし、確認を済ませて再起動し、1 日の待機期間のあとに戻って、指紋、顔、または PIN で確認します。それ以降は、インストーラーが確認されていない開発者のアプリだと警告したうえで、そのままインストールすることを選べます。高度なフローがオフのあいだは、アプリの更新もできません。

**ADB。** お使いのコンピューターから行います。端末の開発者向けオプションで USB デバッグをオンにし、端末でそのコンピューターを許可してから、次を実行します。

```sh
adb install -r <file>.apk
```

Google によると、ADB でのインストールはこれまでどおり使え、待機期間もありません。`-r` は既存のインストールの上からインストールし、そのデータを残します。

Google のページ:
[開発者確認の FAQ](https://developer.android.com/developer-verification/guides/faq)
と [ADB](https://developer.android.com/tools/adb#move)。

## 遊び方

タッチパッドは最初に画面に触れたときに表示され、コントローラーやキーボードを使っている間は消えます。操作 > タッチパッド で、パッドの大きさと不透明度（変えている間はメニューの上にパッドが表示されます）、配置を設定できます。配置は「ボタン」と「ボタンとスティック」から選びます。「ボタンとスティック」では十字キーと同じように動く左スティックが加わり、強化エンジンの自由カメラかファーストパーソン視点をオンにしているとき（操作 > カメラと振動）は、カメラ用の右スティックと、カメラを元に戻すボタン、ファーストパーソン視点に出入りするボタンも加わります。

システム > エンジン では、PlayStation と同じ動作のオリジナルエンジン（既定）と、移植版独自の強化エンジンを選べます。Android では、切り替えるとアプリが再起動します。

## パック

パックはアプリ専用のフォルダー（`Android/data/io.github.etheraura.xgport/files`）に置きます。メニュー（パック > パックをコピーして追加、選んだフォルダーから）でコピーするか、コンピューターから USB でコピーします。パックについては[パック](packs-ja.md)を参照してください。
