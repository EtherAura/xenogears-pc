# past it (<build>/gen/tails.txt, tools/pc_link.py) and that no read takes past the declared
# end, so the bytes the PC leaves out are never wanted (xg-htn.35.154). One per line:
#     <module> | <name> | <declared>/<extent> | <reason>
# with the sizes in hex as tails.txt gives them (a JP or Enhanced extent that differs is a line

# declared of unknown size, or of its true size, so the PC copies the retail bytes the PS1
# reads (battle's perApTable [8][3], whose 25th byte performAttack reads: 926020d1).
