# Reviewed pointer words in untyped memory for tools/state_untyped.py (xg-ety3; docs/CANONICAL_STATES.md
# 17.3): words a converted state carries as the number they were (or, for "stack", as an offset into a game
# stack a stackless load does not keep), each one written again before anything reads it. One per line:
#     <kind> | <place> | <path> | <reason>
# kind, place and path as the scan prints them (a path's indices as []); an empty path is a whole variable.
# A pointer the game does read after a load is not listed here: it gets a type (PC_HEAP_OF, a typed
# variable, scratch64) and leaves the scan. "site" entries are for `state_untyped.py sites` (an allocation
# of a pointer-holding type whose size names none): file (src/ path for both engines) and type.

stack | renderStringWindow | .m1C_currentStringToPrint | main's scratch window: renderString sets the text (a menu's stack buffer, JP) before every print and nothing reads it after
