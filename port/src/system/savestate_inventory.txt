# Every writable static of the platform layer (port/src, objects of the
# `platform` library), for save states (port/src/system/savestate.h):
#   state    saved and loaded by its file's xxxStateIo
#   derived  rebuilt, reset or scratch: nothing to keep across a load
#   host     the host's side: never in a state
# `<file> * <class>` covers a whole file. tools/statecheck.py inventory
# <build> (gates.sh: statevars) fails on a static missing here, so a new
# one is classified (and saved, if the game can see it) when it is added.
